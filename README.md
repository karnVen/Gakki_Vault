* [**Unit I: Introduction & Android Architecture**](./BCA_Sem5_Prep/01_Android_Programming/Unit1_Android_Architecture_and_Intro.md) - History of Android, OHA, OS features, 5-layer architecture, SDK & ADB tooling.

* [**Unit V: Database Management with SQLite**](./BCA_Sem5_Prep/01_Android_Programming/Unit5_SQLite_Database.md) - SQLite features, `SQLiteOpenHelper`, `ContentValues`, `Cursor`, and complete CRUD `DatabaseHelper` implementation.
