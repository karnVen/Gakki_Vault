### 4. 🎤 [Top 50 External Viva Voce Questions & Answers](./03_Top_50_External_Viva_Voce_QnA.md)
50 Rapid-fire questions categorized by:
* **Part 1:** Android 5-Layer Stack, Linux Kernel, HAL, ART vs DVM, APK Structure, `AndroidManifest.xml`, `R.java`, Gradle, ADB.
* **Part 2:** Activity Lifecycle (7 callbacks), Screen rotation lifecycle, Explicit vs Implicit Intents, Back Stack.
* **Part 3:** `dp` vs `sp` vs `px`, `match_parent` vs `wrap_content`, Layout managers, `Adapter`, `ListView` vs `RecyclerView`, `Toast` vs `AlertDialog`.
* **Part 4:** Data storage options, SQLite architecture, `SQLiteOpenHelper`, `onCreate` vs `onUpgrade`, `ContentValues`, `Cursor`.
* **Part 5:** UI Thread & ANR 5-second rule, Services, Broadcast Receivers, Content Providers, Runtime Permissions, 30-second Project Pitch.
