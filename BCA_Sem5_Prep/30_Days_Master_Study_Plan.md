## 5 Golden Rules for 80%+ BCA Exam Scoring:
1. **Always Draw Diagrams First:** In 5-mark and 10-mark questions, examiners award 40-50% of the marks immediately if the diagram (Android Architecture, V-Model, .NET CLR Architecture, Bug Lifecycle, Star Schema, Perceptron) is neat, boxed, and accurately labelled.
2. **Use Tabular Comparisons:** Whenever asked to compare (e.g., DVM vs JVM, Verification vs Validation, Value vs Reference types, Abstract Class vs Interface, OLTP vs OLAP, Supervised vs Unsupervised), use neat comparative tables with 5–8 clear points.
3. **Include Minimal Working Code:** Writing 8–10 lines of clean, compilable Java/C#/Python syntax with comments demonstrates true mastery.
4. **Use Standard Technical Terminology:** Use exact curriculum keywords (e.g., *Ahead-Of-Time compilation*, *Common Language Runtime*, *Basis Path Testing*, *Cyclomatic Complexity*, *CRISP-DM*, *Admissible Heuristic*, *Star Schema*).
5. **Manage Time in the Exam Hall:**
   * First 15 minutes: Read paper and plan Section C questions.
   * Short questions (2 marks): 2-3 sentences each.
   * Medium questions (5 marks): 1 page (definition + diagram/table + short snippet).
   * Long questions (10/12 marks): 2.5–3 pages (detailed breakdown + full architecture diagram + code implementation + numerical solution).
