## 1. Informed (Heuristic) Search Strategies

> **Definition:** Informed search algorithms use domain-specific knowledge via a **heuristic function $h(n)$** to estimate the cheapest path cost from node $n$ to the goal.

* $h(n) = \text{Estimated cost of the cheapest path from node } n \text{ to a goal state}$.
* If $n$ is a goal node, $h(n) = 0$.

---

## 2. The $A^*$ Algorithm (Guaranteed 10-Mark Question)

$A^*$ evaluates nodes by combining the actual cost incurred so far $g(n)$ and the estimated future heuristic cost $h(n)$:

$$f(n) = g(n) + h(n)$$

Where:
* $g(n)$: Exact path cost accumulated from the initial node to current node $n$.
* $h(n)$: Estimated future cost from node $n$ to the nearest goal state.
* $f(n)$: Estimated total cost of path through $n$ to the goal.

```
       Start Node (S)  ──[ Actual Cost g(n) ]──▶  Current Node (n)  ──[ Heuristic h(n) ]──▶  Goal (G)
       └──────────────────────── Total Estimated Cost f(n) = g(n) + h(n) ──────────────────────┘
```

### Condition for $A^*$ Optimality: Admissible Heuristic
* **Admissibility:** A heuristic $h(n)$ is **admissible** if it **never overestimates** the true cost to reach the goal:
  $$0 \le h(n) \le h^*(n)$$
  (where $h^*(n)$ is the true optimal cost to goal).
* **Consistency (Monotonicity):** For every node $n$ and each successor $n'$ generated by action $a$:
  $$h(n) \le c(n, a, n') + h(n')$$

## 3. Memory-Bounded Informed Search

* **Iterative Deepening $A^*$ (IDA*):** Uses an $f$-cost contour limit instead of fixed depth limits, executing depth-first with $O(b d)$ space.
* **Simplified Memory-Bounded $A^*$ (SMA*):** Uses all available physical memory. When full, it drops the worst leaf node with highest $f$-value and backs up its value to parent.

## 4. Adversarial Game Playing: Minimax & Alpha-Beta Pruning (Guaranteed 10-Mark Numerical)

In a two-player zero-sum perfect-information game (Chess, Tic-Tac-Toe):
* **MAX player:** Seeks to maximize the terminal utility score.
* **MIN player:** Seeks to minimize MAX's score.

$$\text{Minimax}(s) = 
\begin{cases} 
\text{Utility}(s) & \text{if Terminal}(s) \\
\max_{a \in Actions(s)} \text{Minimax}(Result(s, a)) & \text{if Player}(s) = MAX \\
\min_{a \in Actions(s)} \text{Minimax}(Result(s, a)) & \text{if Player}(s) = MIN 
\end{cases}$$

---

### Alpha-Beta Pruning:
Pruning eliminates subtrees that cannot influence the final Minimax decision without evaluating every leaf node:
* $\alpha$: Best (highest value) choice found so far along the path for MAX. (Initialized to $-\infty$).
* $\beta$: Best (lowest value) choice found so far along the path for MIN. (Initialized to $+\infty$).
* **Pruning Rule:** Whenever $\alpha \ge \beta$, prune the remaining child branches!

```
                      [ MAX ]  (Root: α=3, β=+∞ -> chooses 3)
                     ╱       ╲
                    ╱         ╲
           [ MIN: 3 ]         [ MIN: <=2 ]  <-- PRUNED (since β=2 <= α=3)
           ╱        ╲         ╱        ╲
        Leaf: 3   Leaf: 5   Leaf: 2   (PRUNED)
```
